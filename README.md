# TradeAnalisis

Настольное приложение для анализа рынка предметов CS:GO (market.csgo.com):
база предметов с фильтрами, история сделок по classid, перцентили, управление
покупками и продажами.

## Скачать

Последняя версия — на странице [Releases](../../releases) этого репозитория.

Установка: скачайте `.msi` и запустите. Приложение ставится в профиль
пользователя, **права администратора не нужны**. Windows может показать
предупреждение «Неизвестный издатель» — это следствие отсутствия цифровой
подписи у сборки; нажмите «Подробнее» → «Выполнить в любом случае».

## Требования

- Windows 10/11, 64 бит
- Java не требуется — среда выполнения встроена в сборку

## Данные и обновления

Настройки, ключи API, база и архив maFile лежат в `%USERPROFILE%\.tradeanalisis`
и **не затрагиваются при обновлении** — можно ставить новую версию поверх старой.

Новая версия не обновляется сама: следи за страницей Releases либо за
[репозиторием с исходным кодом](https://github.com/ParshinSA/TradeAnalisis).

## Как проверить, что файл не подменён

В заметках к каждому релизу лежит SHA-256 файла. Сверь его:

```
Get-FileHash TradeAnalisis-X.Y.Z.msi -Algorithm SHA256
```

Значение должно совпасть с указанным в заметках релиза. Если не совпало —
не запускай файл.
